A comprehensive data analysis of COVID-19 cases across major cities in Pakistan (2020-2022), focusing on Hyderabad, Karachi, Lahore, Islamabad, and Sukkur.

---

## 📌 Project Overview

This project analyzes 20 rows of COVID-19 data to understand:
- Total cases, deaths, and recoveries
- City-wise impact comparison
- Death & Recovery rates
- Peak infection periods
- Vaccination progress

> **Focus City:** Hyderabad, Sindh - Detailed filter
